# 現行操作の補足

確認日: 2026-10-06。GitHub main `1436d26` の実装を基準とする。

既存の管理者/招待者PDFは基本操作の図解として使用できるが、LINE連携追加前の内容である。
以下を併読する。現在の画面とURL例は本書および [画面仕様](screen-specification.md) を優先する。

## プランから回答まで

1. 管理画面へログインし、プラン名・年月・任意のアクセスコードを入力して保存する。保存後はマイプランへ戻る。
2. プラン詳細からイベントを追加する。イベント名は任意、日程・AM/PM・場所は必須。
3. マイプランまたはプラン詳細の配信用URLを開き、招待者に見せたい受付中イベントを選ぶ。
4. URLをコピーして送る。共有URLは `https://rsvphub.bamboosato.com/i/A7X9K2` の形式。例のコードは説明用である。
5. 招待者は、必要ならアクセスコードを入力し、ニックネームと4桁PINで本人識別して出欠を保存する。
6. 管理者はイベント詳細で内訳を確認する。締切後の修正は管理者が代理対応する。

共有URLごとに対象イベント集合が固定される。新しいURLを発行しても、以前のURLにイベントが自動追加されることはない。
URL作成後に締切済となったイベントは表示のみ、削除したイベントは非表示になる。プラン削除で関連URLは使えなくなる。
アクセスコードはURLやLINE配信本文に自動追加されないため、別途伝える。

## LINE友だちの登録

1. 管理者メニューの「アカウント設定」を開く。
2. 「URLコピー」またはQRコードを招待者へ共有する。
3. 招待者がLINEを開き、必要なら公式アカウントを友だち追加する。
4. 入力欄にセットされた登録コードをそのまま送信する。友だち追加だけではRSVP Hubへの登録は完了しない。
5. 管理者が友だち一覧を確認し、必要なら本名などのメモを保存する。メモは120文字以内。

LINEの登録コードは10文字、回答用の短縮招待コードは6文字で、用途が異なる。
同じLINEアカウントを別の管理者に登録する場合は、その管理者のURLからコードを送る。
LINE友だちの名前と出欠回答のニックネームは自動では対応づけられない。

## LINEで招待URLを配信

1. マイプランまたはプラン詳細の「LINE配信」を開く。
2. 配信イベントを選ぶ。受付中の有効イベントのみ選択できる。
3. 配信先を選ぶ。登録済みで、配信対象かつ友だち状態の宛先のみ選択できる。
4. 挨拶文を確認・編集して配信する。空欄ならURLのみ送る。
5. 成功/失敗件数と宛先別結果を確認する。失敗宛先を再送する場合は宛先を選び直す。

1回のAPI上限はイベント100件、宛先50件、挨拶文500文字である。成功はLINE API受付を表し、既読や到達を保証しない。
予約送信・定期配信・自動リマインダーはない。
ブロックした友だちは配信対象外になる。再登録後も配信対象の設定がfalseのままなら、管理者が有効に戻す。

## PIN・通知・削除

- PINを忘れた場合は管理者へ依頼する。管理者はイベント詳細からPINをリセットし、新PINを別途知らせる。回答は保持される。
- リセット後の本人照合には新PINが必要。すでに発行された招待者セッションは24時間の有効期限まで継続する。
- 管理者Push通知は対応ブラウザで通知を許可して使用する。拒否した場合は端末/ブラウザ設定から変更する。LINE配信の設定とは別である。
- オフラインでの回答保存やLINE配信はできない。通信エラー後は保存・送信結果を確認して再操作する。
- 画面の削除は無効化である。開発者向け物理削除は [READMEのMaintenance](../README.md#maintenance) を参照する。

## PDFマニュアルとの主な差分

| 対象 | 差分 |
| --- | --- |
| 管理者PDF | アカウント設定のLINE登録・友だち管理、LINE手動配信の説明が含まれていない。本書の手順を使用する。 |
| 管理者PDFの共有URL説明 | 現在は `/i/{inviteCode}` を発行する。対象集合はURLごとに固定され、プランに1つの固定URLではない。 |
| 両PDFの画面図 | 過去の画面図のため、ボタン配置や現在の表示と一致しない箇所がある。現行画面・画面仕様を参照する。 |
| 招待者PDF | アクセスコード・本人識別・出欠入力・再編集の基本手順は継続。LINE経由で受け取った短縮URLも同じ手順で使用する。 |

PDFの図解自体は今回変更していない。基本操作の参考資料とし、本書で現行機能を補完する。
